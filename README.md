# WordVault 1.7 – automaattiset käännösehdotukset

Julkaise kaikki seitsemän tiedostoa nykyiseen GitHubin WordVault-repositorioon. Render Static Site julkaisee muutokset.

1. Kuvaa suomenkielinen teksti.
2. OCR erottaa sanat.
3. WordVault hakee puuttuville sanoille englanninkieliset käännösehdotukset MyMemory-palvelusta.
4. Tarkista ehdotukset ja paina Tallenna tunnistetut sanaparit.
5. Harjoittele sanoja.

Käännöspalvelu vaatii verkkoyhteyden ja siinä on ilmaisrajoituksia. Jos käännöspalvelu ei vastaa tai estää selainpyynnön, yksittäiset sanat näkyvät mutta käännöskentät jäävät tyhjiksi. MyMemory-palvelulle lähetetään tunnistetut sanat yksi kerrallaan; älä kuvaa arkaluonteista tekstiä. Suomen taivutusmuodot voivat tuottaa epätarkkoja käännöksiä. Paikallisesti tallennetut sanat säilyvät entisellä avaimella.
